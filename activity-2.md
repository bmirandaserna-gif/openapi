# Construcción de una especificación OpenAPI

Utiliza el fichero adjunto `spec.txt` que contiene una descripción informal de una API REST para gestionar tareas.

El objetivo es utilizar **OpenCode** para transformar esta descripción informal en una **especificación formal OpenAPI**.

## Objetivo

Crear el fichero:

`openapi.yaml`

que describa la API de tareas de forma suficiente para que otro desarrollador pueda implementar el servicio a partir de la especificación.

## Proceso

Utiliza OpenCode para:

1. Analizar la descripción informal de `spec.txt`.

2. Identificar las decisiones necesarias para convertirla en una especificación OpenAPI.

3. Construir `openapi.yaml`.

4. Revisar y validar la especificación generada.

5. Corregir los problemas que se detecten.

No se proporciona una especificación OpenAPI de referencia. Las decisiones de diseño que no estén determinadas explícitamente en los requisitos deberán resolverse durante el proceso.

## Entrega

El fichero `openapi.yaml`.
