### 2. Añadir tags para mejor documentación
```yaml
get:
  summary: Consultar todas las tareas
  operationId: getTasks
  tags:
    - Tareas
  responses: ...
```

### 3. Considerar PATCH para actualizaciones parciais
Actualmente usan PUT para modificaciones completas. Si se quiere soportar actualizaciones parcia:
- Añadir `patch` operation en `/tasks/{taskId}` con `schema: $ref: '#/components/schemas/TaskPatch'`
- `TaskPatch` sería un objeto opcional con solo los campos que se van a actualizar

### 4. Añadir cabezera de aceptación
```yaml
get:
  summary: Consultar todas las tareas
  operationId: getTasks
  responses:
    '200':
      description: Lista de tareas
      content:
        application/json:
          schema: ...
```
*Opcional*: Añadir `produces: [application/json]` a nivel de path o global.

### 5. Error schema enriquecido
